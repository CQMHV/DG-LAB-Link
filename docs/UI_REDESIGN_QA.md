## 交互与可访问性

- 浏览器模拟流程：添加设备 → 蓝牙扫描 → 分别连接两台设备 → 打开指定设备控制 → 设置 20/30 强度与音频输入源 → 开始输出 → 返回总览 → 单设备停止，确认基础强度保留。
- 管理连接 → V3 连接 → 配对弹窗；Shift+Tab 直接到达底部紧急停止，Enter 归零全部设备；Escape 关闭并恢复焦点。V4 与 BLE 设备保留。
- BLE 详情：键盘展开参数、编辑软上限为 90、保存后卡片与底栏上限同时更新；滚动区保留关闭入口及底部紧急停止。
- 640×520 独立设备窗口：A/B 调整、开始输出及紧急停止可见，页面无横向溢出。
- 自动回归覆盖：无快照时安全入口、普通命令等待中停止、迟到开始请求不能恢复输出、音频停止、显式同步基准、导航保留基准、基准/选中设备断开、弹窗焦点、BLE 参数有效性和草稿保留。
