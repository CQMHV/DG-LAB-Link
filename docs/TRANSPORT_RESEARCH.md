## 证据

- 复用官方 Android 4.2.6 APK：文件名 `dglab_online_426_0903_220556.apk`，大小 97,929,615 字节，SHA-256 `ff68f0d4d6606a1f8a1d0b2d6b8bed684b8af45a0d95bcd906dbf15cdffc0c1a`。来源及提取方法见 [输入模式调查](INPUT_MODES_RESEARCH.md)。只检查静态资源，未安装或运行 APP。
- APK 解压产物保存在 Git 忽略的 `tmp/mode-research/`，不纳入产品二进制或依赖，也不复制官方 APP 实现代码。
- [btleplug 0.13.3](https://docs.rs/btleplug/0.13.3/btleplug/)使用 Windows 原生 GATT 后端，支持 Tokio；许可证为 MIT/Apache-2.0/BSD-3-Clause，见依赖来源声明。

## 已确认的实现约束

| 项目 | 结论 |
| --- | --- |
| V3 WS 波形 | 使用 `msg` 直接转发 `pulse-A/B`，由 core 调度，不使用 Relay 的长时循环任务。 |
| V3 WS 相对强度 | APP 每条命令固定增减 1，忽略携带的增减数值；较大调整必须逐步等待实际强度反馈。 |
| V3 WS 元数据 | 仅有两路强度和上限，不能推断型号、电量或负载状态。 |
| BLE 设备 | 首版只支持郊狼 3.0，公开名称 `47L121000`，连接后还须检查服务和特征。 |
| BLE 初始化 | 订阅消息、电量及可用通道反馈；无输出 B0 相对 +0 获取当前强度，再下发 BF。 |
| BF 默认 | 两路软上限各 100，频率平衡各 160，强度平衡各 0。每次重连重写。 |
| BF 确认 | 没有设备回执，也没有公开读取当前 BF 参数的接口；只能报告已下发。 |
| 实体旋钮 | B1 更新实际强度，作为后续控制依据；不得套用 WS 的电脑端强度锁来回调实体旋钮。 |
| 标准模式 | APP 的 BC 标准模式请求和 BD 对应回执属于公开协议外扩展。首版仅标准模式。 |
| 旋钮保护 | APP 在读取的固件版本首字节 >=10 时支持 C4，默认开启、值 10；关闭使用 255。 |
| 连接输出 | 官方 APP 默认连接后静音。静音与基础强度归零不同；DG-LAB Link 重连不恢复输出。 |

APK 关键证据位于格式化主 bundle `5986.d2d37ec448.js`：BLE 驱动 6528–6880；B1 处理 6836–6847；控制器采纳反馈 12029–12051；默认参数 22124–22136；V3 相对调整 16325–16346。行号仅用于本地分析产物定位。

## 首版边界与待验

Windows 首版允许一个 V4 WS 连接、一个 V3 WS 连接与多个 BLE 会话并存，复用现有输入源、设备控制、安全代次和四个程序入口。V3 WS 不支持修改 BLE 参数；BLE 首版不包含郊狼 2.0、温柔模式、OTA 或设备绑定管理。

静态证据不能证明真实设备已执行写入。Windows 蓝牙权限、设备占用、连接时序、固件扩展、实体旋钮、负载通知、持续输出、音频与触控及紧急停止，必须按 [真机验收清单](REAL_DEVICE_CHECKLIST.md) 记录。模拟器或协议测试通过不代表真机验收通过。
