# 原生输入源插件验收

日期：2026-10-02。环境：Windows、本机 Rust / Node.js 工具链。本报告记录本次执行的自动验证；不将模拟协议、进程测试或构建结果视为真机验收。

## 交付范围

- 固定波形保留在核心；触控和音频迁入真正的原生独立进程插件，移除核心中的采集、播放和触控运行实现。
- 提供本地 `.dglabplugin` 安装、更新、卸载、多实例、启用、启动、停止、配置与通道绑定。预装插件和第三方共用公开 SDK、业务接口、配置事务和语义 UI。
- GUI、CLI、HTTP MCP、stdio MCP 共用同一个核心；插件不增加持有者。实例定义和配置持久保存，重启不恢复插件进程、设备连接或输出。
- 普通停止只清空目标设备波形，保留基础强度、插件进程和音频活动；移除公开急停功能。最后持有者退出仍清理全部链路并归零，总期限十秒。
- 提供开发 SDK、真实可执行示例、独立 Rust 项目模板、公共打包器及开发／生产预装包生成流程。

## 已覆盖行为

包与 SDK 测试覆盖路径穿越、Windows 路径别名、大小写冲突、PE 入口、包内容一致、协议长度限制和持久注册表。真实第三方 exe 验证多实例、按需启动、语义 UI、反向业务调用、配置并发与失败回滚、暂存更新失败以及启动与退出竞争。

帧和设备集成测试覆盖最新帧一次消费、500ms 过期、旧进程身份、旧绑定代次、递增序列号及输入所有者容量回收。第三方真实进程向本机模拟 V4 Relay 输出，插件停止只影响其 A 通道，另一通道固定波形继续；普通停止不归零，旧帧和已接受的旧启动请求不能恢复输出。

绑定失效时先清除该绑定的插件发送邮箱和实例级待输入，再发布新绑定；未变化通道的待输入与序列保护保留。新增回归覆盖停止后快速重新激活不会发送旧触点，以及 A 失效时 B 输入和乱序保护不被清空。

预装插件测试覆盖触控路由、映射、释放、所有者撤销、租期到期、背景波形及音频解码、视频音轨选择、录音和映射。旧触控命令通过真实原生插件处理，通道清理保持另一通道和背景行为。插件业务调用没有第一方专用权限路径。

HTTP 与 stdio MCP 验证第三方包安装、跨入口配置、插件／输入源资源共享、相同错误结构及急停工具移除。共享运行时继续验证鉴权、非法 Origin、容量限制、并发冷启动、持有者释放、异常连接、跨入口停止代次和最终清理。

模拟 Relay 的退出测试先停止普通回包并排空已有请求，再释放最后持有者；严格验证最后三条清理命令依次为清空、A 归零、B 归零，随后收到 WebSocket Close。另用临时延迟回包复现 Windows 10053 退出竞态并验证修复，最终测试不保留人为延迟。

发布产物冒烟进一步暴露短 CLI 连接释放时的 Windows 10053／10054：业务结果已返回，但服务端提前丢弃仍有尾随心跳的 TCP 连接。新增回归在旧实现稳定失败；修复后验证 100 次短连接、Release 后流水心跳和配置写请求只被排空、等待对端 Close、8 次快速最后持有者 ACK。设备清理与接口收尾共用十秒总截止。

前端验证通用控件、配置草稿、文件选择、实例与插件管理、显式停止后不被轮询启动，以及设备普通停止保持独立可用。未进行本轮桌面窗口的人工视觉与键盘验收。

## 发布产物

裸可执行文件位于 `src-tauri/target/release/`：

- `dg-lab-link-core.exe`
- `dg-lab-link-cli.exe`
- `dg-lab-link-mcp.exe`
- `dg-lab-link-gui.exe`

同目录 `plugins/` 包含 `cn.dglab.link.touch.dglabplugin` 与 `cn.dglab.link.audio.dglabplugin`。发布时保留该目录。构建还生成插件入口和开发打包工具；运行应用无需额外常驻插件宿主程序。

使用独立配置目录运行实际 release CLI，验证首次创建两个预装包和默认实例且不启动插件、真实触控语义 UI 的按需启动、同包两个独立进程、停止一个保留另一个、80 次短 CLI 连接全部成功，以及卸载后重启保留禁用实例且不重新安装。三次正常最后持有者退出分别约 0.219、0.203、0.219 秒完成本机链路关闭；这些场景没有连接实体设备。

另通过独立测试 core 的已确认进程句柄模拟异常退出，Windows Job Object 回收两个真实触控插件子进程，后台 CLI 持有者也退出；重启后的实例均停止，不恢复活动。未触及用户默认配置或其他运行进程。
